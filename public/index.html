GulfCoastMesh · Mobile

For off-grid communication when it matters most.

Decentralized Off-grid Community-powered

Mobile’s Gulf Coast Mesh is part of a community-built mesh communication network using MeshCore. It gives the general public text messaging that works without cell towers, internet, or electricity from the grid — using low-cost LoRa radio companions that pair with handheld devices you already own, like phones and tablets. Our network is designed for emergency preparedness, community building, and resilient communication.
